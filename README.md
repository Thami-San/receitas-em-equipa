# Receitas em Equipa 🍳

Coleção colaborativa de receitas, criada como exercício de Git e GitHub.

## Sobre o projeto
Este repositório reúne receitas organizadas por categoria, desenvolvidas
em conjunto por três elementos como prática de fluxo de trabalho colaborativo
com Git (commits, branches, merges).

## Estrutura
- `entradas/` — receitas de entrada
- `pratos-principais/` — pratos principais
- `sobremesas/` — sobremesas
- `bebidas/` — bebidas e cocktails

## Equipa
- Thamires — Elemento A
- Fernanda — Elemento B
- Mairane — Elemento C

## Objetivo
Este repositório reúne estrutura de um website de receitas organizadas por categoria (entradas, pratos principais, sobremesas e bebidas), desenvolvida por três formandas como exercício prático de colaboração em Git e GitHub. Cada pasta representa uma categoria de receitas, e a estrutura foi definida em conjunto pela equipa.
